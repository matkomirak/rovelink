## 2. Architecture overview

Understanding this before making changes is mandatory.

```
Providers (Azure, Proxmox, vCenter)
    │
    ▼  listVms() / listVmsWithHints()
External Objects table  ←── SyncWorker caches provider data here
    │
    ▼  Pipeline sync (server/routes/pipelines.ts)
CMDB Accounts (NetBox, iDoIT, ServiceNow)
    │
    ▼  NetBoxAdapter / IdoitAdapter upsert
CMDB stores governance data (tenant, role, automatable)
    │
    ▼  GateEvaluator reads CMDB ONLY
Automation GATE  ──── BLOCK → write reason back to CMDB
    │
    ▼  PASS only
Automation Inventories (Ansible-consumable host lists)
    │
    ▼  Job Templates
AWX / Ansible runner execution
    │
    ▼  WebSocket log stream
Frontend run console
```

## 3. Gap 1 — Real Ansible / AWX execution engine

### Current state
`server/services/fake-runner.ts` contains `FakeRunner`, a class that simulates playbook runs
with canned log output and a random 20% failure rate. It does not call Ansible or AWX.
It is used in `server/routes.ts` for all job run endpoints.

### Goal
Replace `FakeRunner` with a real execution engine that supports two modes:
- **Mode A — AWX/Controller**: Call the AWX REST API to launch a job template and stream its output.
- **Mode B — Local Ansible**: Spawn `ansible-playbook` as a child process and stream stdout.

The mode is selected per-job-template via a new `runnerMode` field.

### 3.2 AWX runner service

**Create: `server/services/awx-runner.ts`**

```typescript
/**
 * AWX Runner — launches AWX job templates via REST API and streams output.
 *
 * AWX API reference: https://docs.ansible.com/automation-controller/latest/html/controllerapi/
 *
 * Flow:
 *   1. POST /api/v2/job_templates/:id/launch/  → returns { job: { id } }
 *   2. Poll GET /api/v2/jobs/:jobId/            → wait for status != "pending" | "waiting" | "running"
 *   3. Stream GET /api/v2/jobs/:jobId/stdout/?format=txt  → pipe to onLog callback
 *   4. Return final status and summary
 */

import axios, { AxiosInstance } from "axios";
import https from "https";

export interface AwxConfig {
  url: string;          // Base URL, e.g. https://awx.example.com
  token: string;        // Personal access token
  verifySsl: boolean;
}

export interface AwxLaunchOptions {
  templateId: number;
  inventoryId?: number;   // Override AWX inventory
  limitExpr?: string;     // --limit expression
  extraVars?: Record<string, any>;
  checkMode?: boolean;
}

export interface AwxRunResult {
  status: "ok" | "failed" | "error" | "cancelled";
  jobId: number;
  summary: {
    hosts: number;
    ok: number;
    changed: number;
    failed: number;
    unreachable: number;
  };
  logs: string;
}

export class AwxRunner {
  private client: AxiosInstance;

  constructor(config: AwxConfig) {
    this.client = axios.create({
      baseURL: config.url.replace(/\/$/, ""),
      headers: {
        Authorization: `Bearer ${config.token}`,
        "Content-Type": "application/json",
      },
      httpsAgent: new https.Agent({ rejectUnauthorized: config.verifySsl }),
      timeout: 30000,
    });
  }

  async testConnection(): Promise<{ ok: boolean; version?: string; error?: string }> {
    try {
      const res = await this.client.get("/api/v2/ping/");
      return { ok: true, version: res.data?.version };
    } catch (err: any) {
      return { ok: false, error: err.message };
    }
  }

  async launch(options: AwxLaunchOptions, onLog: (line: string) => void): Promise<AwxRunResult> {
    // Step 1: Launch the job
    const payload: Record<string, any> = {};
    if (options.inventoryId) payload.inventory = options.inventoryId;
    if (options.limitExpr) payload.limit = options.limitExpr;
    if (options.extraVars) payload.extra_vars = JSON.stringify(options.extraVars);
    if (options.checkMode) payload.job_type = "check";

    const launchRes = await this.client.post(
      `/api/v2/job_templates/${options.templateId}/launch/`,
      payload
    );
    const jobId: number = launchRes.data.job;
    onLog(`[rovelink] AWX job ${jobId} launched\n`);

    // Step 2: Poll until finished
    const terminalStatuses = new Set(["successful", "failed", "error", "canceled"]);
    let jobData: any;
    while (true) {
      await new Promise((r) => setTimeout(r, 3000)); // poll every 3s
      const statusRes = await this.client.get(`/api/v2/jobs/${jobId}/`);
      jobData = statusRes.data;
      if (terminalStatuses.has(jobData.status)) break;
    }

    // Step 3: Stream stdout
    try {
      const stdoutRes = await this.client.get(`/api/v2/jobs/${jobId}/stdout/`, {
        params: { format: "txt" },
        responseType: "text",
      });
      const lines: string[] = (stdoutRes.data as string).split("\n");
      for (const line of lines) {
        onLog(line + "\n");
      }
    } catch {
      onLog("[rovelink] Could not retrieve job stdout\n");
    }

    // Step 4: Build result
    const hostSummary = jobData.summary_fields?.hosts || {};
    const totals = Object.values(hostSummary as Record<string, any>).reduce(
      (acc: any, h: any) => {
        acc.ok += h.ok || 0;
        acc.changed += h.changed || 0;
        acc.failed += h.failures || 0;
        acc.unreachable += h.unreachable || 0;
        acc.hosts += 1;
        return acc;
      },
      { hosts: 0, ok: 0, changed: 0, failed: 0, unreachable: 0 }
    );

    const statusMap: Record<string, AwxRunResult["status"]> = {
      successful: "ok",
      failed: "failed",
      error: "error",
      canceled: "cancelled",
    };

    return {
      status: statusMap[jobData.status] ?? "error",
      jobId,
      summary: totals,
      logs: "", // already streamed via onLog
    };
  }
}
```

### 3.3 Local Ansible runner service

**Create: `server/services/local-runner.ts`**

```typescript
/**
 * Local Ansible runner — spawns ansible-playbook as a child process.
 *
 * Requirements on the host:
 *   - ansible-playbook must be in PATH
 *   - The inventory file referenced in the job template must exist
 *   - SSH keys / credentials must be pre-configured on the host
 *
 * Security note: limitExpr and extraVars are shell-escaped before use.
 * Never interpolate user input directly into the command string.
 */

import { spawn } from "child_process";
import { escapeShellArg } from "../utils/shell";  // create this utility — see below

export interface LocalRunOptions {
  playbookPath: string;     // Absolute or relative path to playbook file
  inventoryPath: string;    // Path to inventory file or directory
  limitExpr?: string;
  extraVars?: Record<string, any>;
  checkMode?: boolean;
  diffMode?: boolean;
  credentialPath?: string;  // Path to SSH private key
}

export interface LocalRunResult {
  status: "ok" | "failed" | "error";
  exitCode: number;
  logs: string;
  summary: {
    hosts: number;
    ok: number;
    changed: number;
    failed: number;
    unreachable: number;
  };
}

export class LocalRunner {
  async execute(options: LocalRunOptions, onLog: (line: string) => void): Promise<LocalRunResult> {
    const args: string[] = ["-i", options.inventoryPath, options.playbookPath];

    if (options.limitExpr) args.push("--limit", options.limitExpr);
    if (options.checkMode) args.push("--check");
    if (options.diffMode) args.push("--diff");
    if (options.credentialPath) args.push("--private-key", options.credentialPath);
    if (options.extraVars) {
      args.push("--extra-vars", JSON.stringify(options.extraVars));
    }

    return new Promise((resolve) => {
      const logs: string[] = [];
      // Simple PLAY RECAP parser
      const summary = { hosts: 0, ok: 0, changed: 0, failed: 0, unreachable: 0 };

      const proc = spawn("ansible-playbook", args, {
        env: { ...process.env, ANSIBLE_FORCE_COLOR: "0", ANSIBLE_NOCOLOR: "1" },
      });

      const handleLine = (line: string) => {
        logs.push(line);
        onLog(line + "\n");
        // Parse PLAY RECAP lines:  hostname : ok=N  changed=N  unreachable=N  failed=N
        const recapMatch = line.match(/^(\S+)\s+:\s+ok=(\d+)\s+changed=(\d+)\s+unreachable=(\d+)\s+failed=(\d+)/);
        if (recapMatch) {
          summary.hosts += 1;
          summary.ok += parseInt(recapMatch[2], 10);
          summary.changed += parseInt(recapMatch[3], 10);
          summary.unreachable += parseInt(recapMatch[4], 10);
          summary.failed += parseInt(recapMatch[5], 10);
        }
      };

      proc.stdout.on("data", (chunk: Buffer) => {
        chunk.toString().split("\n").filter(Boolean).forEach(handleLine);
      });
      proc.stderr.on("data", (chunk: Buffer) => {
        chunk.toString().split("\n").filter(Boolean).forEach((l) => handleLine(`[stderr] ${l}`));
      });

      proc.on("close", (code) => {
        resolve({
          status: code === 0 ? "ok" : "failed",
          exitCode: code ?? 1,
          logs: logs.join("\n"),
          summary,
        });
      });

      proc.on("error", (err) => {
        onLog(`[rovelink] Failed to start ansible-playbook: ${err.message}\n`);
        resolve({ status: "error", exitCode: -1, logs: err.message, summary });
      });
    });
  }
}
```

### 3.4 Runner dispatcher

**Create: `server/services/runner-dispatcher.ts`**

```typescript
/**
 * Runner Dispatcher — selects AWX or local runner based on job template config.
 * This replaces FakeRunner in all route handlers.
 */

import { db } from "../db";
import { jobTemplates, settings } from "../../shared/schema";
import { eq } from "drizzle-orm";
import { AwxRunner } from "./awx-runner";
import { LocalRunner } from "./local-runner";
import { decryptSecret } from "./secrets";
import type { JobRun } from "../../shared/schema";

export interface RunResult {
  status: "ok" | "failed" | "error" | "cancelled";
  summary: { hosts: number; ok: number; changed: number; failed: number };
  logs: string;
}

export async function dispatchRun(run: JobRun, onLog: (line: string) => void): Promise<RunResult> {
  // Load template to get runnerMode
  const template = await db.query.jobTemplates.findFirst({
    where: eq(jobTemplates.id, run.templateId),
  });
  if (!template) throw new Error(`Job template ${run.templateId} not found`);

  if (template.runnerMode === "awx") {
    return runViaAwx(run, template, onLog);
  }
  return runLocally(run, template, onLog);
}

async function runViaAwx(run: JobRun, template: any, onLog: (line: string) => void): Promise<RunResult> {
  // Load AWX credentials from settings
  const rows = await db.query.settings.findMany();
  const settingsMap = Object.fromEntries(rows.map((r: any) => [r.key, r.value]));

  const awxUrl = settingsMap["awx_url"];
  const awxTokenEnc = settingsMap["awx_token"];
  const verifySsl = settingsMap["awx_verify_ssl"] !== "false";

  if (!awxUrl || !awxTokenEnc) {
    throw new Error("AWX not configured. Set awx_url and awx_token in Settings.");
  }

  const runner = new AwxRunner({
    url: awxUrl,
    token: decryptSecret(awxTokenEnc),
    verifySsl,
  });

  const result = await runner.launch(
    {
      templateId: template.awxTemplateId,
      inventoryId: template.awxInventoryId ?? undefined,
      limitExpr: run.limitExpr ?? undefined,
      extraVars: (template.extraVars as Record<string, any>) ?? {},
      checkMode: template.checkMode ?? false,
    },
    onLog
  );

  return {
    status: result.status === "cancelled" ? "failed" : result.status,
    summary: result.summary,
    logs: result.logs,
  };
}

async function runLocally(run: JobRun, template: any, onLog: (line: string) => void): Promise<RunResult> {
  const runner = new LocalRunner();
  const result = await runner.execute(
    {
      playbookPath: template.playbook,
      inventoryPath: "inventory/netbox.yml", // default inventory path
      limitExpr: run.limitExpr ?? undefined,
      extraVars: (template.extraVars as Record<string, any>) ?? {},
      checkMode: template.checkMode ?? false,
      diffMode: template.diffMode ?? false,
    },
    onLog
  );

  return {
    status: result.status,
    summary: result.summary,
    logs: result.logs,
  };
}
```

### 4.1 Create the vCenter collector

**Create: `server/services/providers/vcenter.ts`**

```typescript
/**
 * VMware vCenter Provider
 * Uses the vSphere REST API (available since vCenter 6.7u3+)
 * API docs: https://developer.vmware.com/apis/vsphere-automation/latest/
 *
 * Authentication: session-based. Calls POST /api/session to get a session token,
 * then sends it as vmware-api-session-id header.
 */

import axios, { AxiosInstance } from "axios";
import https from "https";
import { IProviderCollector, NormalizedVm, TestConnectionResult, ProviderOutput, ObservedAsset } from "./types";

export interface VCenterConfig {
  url: string;             // https://vcenter.example.com
  username: string;        // administrator@vsphere.local
  password: string;        // encrypted at rest, decrypted before use
  verify_ssl: boolean;
  datacenter?: string;     // Optional: filter by datacenter name
  cluster?: string;        // Optional: filter by cluster name
}

interface VSphereVm {
  vm: string;              // VM managed object reference, e.g. "vm-123"
  name: string;
  power_state: string;     // "POWERED_ON" | "POWERED_OFF" | "SUSPENDED"
  cpu_count?: number;
  memory_size_MiB?: number;
}

interface VSphereVmDetails {
  identity?: { name?: string; instance_uuid?: string };
  power_state?: { state?: string };
  cpu?: { count?: number };
  memory?: { size_MiB?: number };
  guest_OS?: string;
  nics?: Record<string, { mac_address?: string }>;
}

interface VSphereGuestInfo {
  ip_address?: string;
  host_name?: string;
  family?: string;  // "WINDOWS" | "LINUX" etc.
  full_name?: { default_message?: string };
}

export class VCenterCollector implements IProviderCollector {
  private config: VCenterConfig;
  private client: AxiosInstance;
  private sessionToken?: string;

  constructor(config: VCenterConfig) {
    this.config = config;
    this.client = axios.create({
      baseURL: config.url.replace(/\/$/, ""),
      httpsAgent: new https.Agent({ rejectUnauthorized: config.verify_ssl }),
      timeout: 30000,
    });
  }

  private async authenticate(): Promise<void> {
    if (this.sessionToken) return;

    const res = await this.client.post(
      "/api/session",
      {},
      {
        auth: { username: this.config.username, password: this.config.password },
      }
    );
    // Response body is the session token string (with quotes — trim them)
    this.sessionToken = (res.data as string).replace(/"/g, "");
    this.client.defaults.headers.common["vmware-api-session-id"] = this.sessionToken;
  }

  private async refreshSession(): Promise<void> {
    this.sessionToken = undefined;
    await this.authenticate();
  }

  async testConnection(): Promise<TestConnectionResult> {
    try {
      await this.authenticate();
      const res = await this.client.get("/api/vcenter/datacenter");
      const datacenters = res.data as Array<{ name: string }>;
      return {
        ok: true,
        details: `Connected. Datacenters: ${datacenters.map((d) => d.name).join(", ")}`,
      };
    } catch (err: any) {
      return { ok: false, error: err.message };
    }
  }

  async listVms(): Promise<NormalizedVm[]> {
    const outputs = await this.listVmsWithHints?.() ?? [];
    return outputs.map((o) => ({
      externalId: o.observed.provider_id,
      name: o.observed.name,
      provider: "vcenter",
      primaryIp4: o.observed.primaryIp4,
      vcpus: o.observed.vcpus,
      memory: o.observed.memory,
      platform: o.observed.platform,
      status: o.observed.status,
      description: o.observed.description,
      tags: [],
      raw: o.hints?.raw,
    }));
  }

  async listVmsWithHints(): Promise<ProviderOutput[]> {
    await this.authenticate();

    // Fetch VM list
    const params: Record<string, string> = {};
    const vmListRes = await this.client.get("/api/vcenter/vm", { params }).catch(async (e) => {
      if (e.response?.status === 401) {
        await this.refreshSession();
        return this.client.get("/api/vcenter/vm", { params });
      }
      throw e;
    });

    const vms: VSphereVm[] = vmListRes.data;
    const outputs: ProviderOutput[] = [];

    for (const vm of vms) {
      try {
        // Fetch details (CPU, memory, OS)
        const detailRes = await this.client.get(`/api/vcenter/vm/${vm.vm}`);
        const detail: VSphereVmDetails = detailRes.data;

        // Try to get guest info (IP address, hostname)
        let guestIp: string | undefined;
        let platform: string | undefined;
        try {
          const guestRes = await this.client.get(`/api/vcenter/vm/${vm.vm}/guest/identity`);
          const guest: VSphereGuestInfo = guestRes.data;
          guestIp = guest.ip_address;
          platform = guest.family?.toLowerCase().includes("windows") ? "windows" : "linux";
        } catch {
          // Guest tools not running — acceptable
        }

        const powerMap: Record<string, string> = {
          POWERED_ON: "running",
          POWERED_OFF: "offline",
          SUSPENDED: "staged",
        };

        const observed: ObservedAsset = {
          provider_id: vm.vm,
          name: vm.name,
          provider: "vcenter",
          status: powerMap[vm.power_state] ?? "offline",
          last_seen_at: new Date(),
          primaryIp4: guestIp,
          vcpus: detail.cpu?.count ?? vm.cpu_count,
          memory: detail.memory?.size_MiB ?? vm.memory_size_MiB,
          platform,
          cluster: this.config.cluster,
          site: this.config.datacenter,
        };

        outputs.push({
          observed,
          hints: { raw: { vm, detail } },
        });
      } catch (err: any) {
        // Log but continue — one bad VM should not abort the whole sync
        console.error(`[vcenter] Failed to fetch details for VM ${vm.vm} (${vm.name}): ${err.message}`);
      }
    }

    return outputs;
  }
}

export function createVCenterCollector(config: any): IProviderCollector {
  return new VCenterCollector(config as VCenterConfig);
}
```

### 5.2 Update the adapter

**File: `server/services/idoit-adapter.ts`** — replace the stub methods:

```typescript
import axios, { AxiosInstance } from "axios";

export interface IdoitConfig {
  url: string;     // https://idoit.example.com
  apiKey: string;  // iDoIT API key
  username?: string; // Optional: for session-based auth
  password?: string;
}

export class IdoitAdapter {
  private config: IdoitConfig;
  private client: AxiosInstance;
  private sessionId?: string;
  private requestId = 1;

  constructor(config: IdoitConfig) {
    this.config = config;
    this.client = axios.create({
      baseURL: config.url.replace(/\/$/, ""),
      headers: { "Content-Type": "application/json" },
      timeout: 30000,
    });
  }

  private async rpc(method: string, params: Record<string, any>): Promise<any> {
    const body = {
      version: "2.0",
      method,
      params: { apikey: this.config.apiKey, ...params },
      id: this.requestId++,
    };
    const res = await this.client.post("/src/jsonrpc.php", body);
    if (res.data.error) {
      throw new Error(`iDoIT RPC error [${res.data.error.code}]: ${res.data.error.message}`);
    }
    return res.data.result;
  }

  async test(): Promise<{ ok: boolean; version?: string; error?: string }> {
    try {
      const result = await this.rpc("idoit.version", {});
      return { ok: true, version: result?.version };
    } catch (err: any) {
      return { ok: false, error: err.message };
    }
  }

  /**
   * Upsert a CI into iDoIT.
   * Strategy: search by title first. If found, update. If not, create.
   *
   * @param targetType - iDoIT object type, e.g. "VirtualServer" → mapped to iDoIT type constant
   * @param obj        - Fields to write. Must include `name`.
   * @param matchBy    - Fields to match on (default: ["name"])
   */
  async upsert(targetType: string, obj: any, matchBy: string[] = ["name"]): Promise<any> {
    const typeId = this.resolveTypeId(targetType);

    // Search for existing object by name
    const searchResult = await this.rpc("cmdb.objects.read", {
      filter: { type: typeId, title: obj.name },
    });

    const existing = Array.isArray(searchResult) ? searchResult[0] : null;

    if (existing) {
      // Update: write category data
      await this.writeCategoryData(existing.id, obj);
      return { action: "updated", id: existing.id };
    } else {
      // Create new object
      const created = await this.rpc("cmdb.object.create", {
        type: typeId,
        title: obj.name,
      });
      await this.writeCategoryData(created.id, obj);
      return { action: "created", id: created.id };
    }
  }

  private async writeCategoryData(objectId: number, obj: any): Promise<void> {
    // Write to C__CATG__VIRTUAL_MACHINE category for VirtualServer objects
    const catData: Record<string, any> = {};
    if (obj.vcpus !== undefined)   catData.cpu_cores = obj.vcpus;
    if (obj.memory !== undefined)  catData.memory_mb = obj.memory;
    if (obj.platform !== undefined) catData.operating_system = obj.platform;
    if (obj.primaryIp4)            catData.primary_ip = obj.primaryIp4;

    if (Object.keys(catData).length > 0) {
      await this.rpc("cmdb.category.save", {
        object: objectId,
        catconst: "C__CATG__VIRTUAL_MACHINE",
        data: catData,
      });
    }
  }

  private resolveTypeId(targetType: string): number {
    // iDoIT object type constants
    const typeMap: Record<string, number> = {
      VirtualServer:  1011,
      PhysicalServer: 5,
      Application:    58,
      Interface:      76,
      Site:           6,
      Tenant:         1,
    };
    const id = typeMap[targetType];
    if (!id) throw new Error(`Unknown iDoIT object type: ${targetType}`);
    return id;
  }

  // objectTypes() and validate() remain unchanged
}
```

```typescript
/**
 * ServiceNow CMDB Adapter
 * Uses the ServiceNow Table API: https://docs.servicenow.com/bundle/washingtondc-api-reference/page/integrate/inbound-rest/concept/c_TableAPI.html
 *
 * Authentication: Basic auth (username + password) or OAuth2.
 * For v1 implement Basic auth. OAuth2 can be added later.
 */

import axios, { AxiosInstance } from "axios";

export interface ServiceNowConfig {
  url: string;       // https://myinstance.service-now.com
  username: string;
  password: string;  // encrypted at rest
}

export class ServiceNowAdapter {
  private config: ServiceNowConfig;
  private client: AxiosInstance;

  constructor(config: ServiceNowConfig) {
    this.config = config;
    this.client = axios.create({
      baseURL: config.url.replace(/\/$/, ""),
      auth: { username: config.username, password: config.password },
      headers: { "Content-Type": "application/json", Accept: "application/json" },
      timeout: 30000,
    });
  }

  objectTypes(): string[] {
    return [
      "cmdb_ci_vm_instance",    // Virtual Machine Instance
      "cmdb_ci_server",         // Server
      "cmdb_ci_network_adapter", // Network Adapter
      "cmdb_ci_ip_address",     // IP Address
    ];
  }

  async test(): Promise<{ ok: boolean; version?: string; error?: string }> {
    try {
      // Hit the now/table/sys_properties endpoint — available on all instances
      const res = await this.client.get("/api/now/table/sys_properties", {
        params: { sysparm_limit: 1, sysparm_fields: "name" },
      });
      return { ok: true };
    } catch (err: any) {
      return { ok: false, error: err.message };
    }
  }

  /**
   * Upsert a CI into ServiceNow.
   * Uses GET to find by name, then PATCH or POST.
   */
  async upsert(targetType: string, obj: any, matchBy: string[] = ["name"]): Promise<any> {
    const table = this.resolveTable(targetType);

    // Search for existing CI
    const query = matchBy.map((f) => `${f}=${encodeURIComponent(obj[f] ?? "")}`).join("^");
    const searchRes = await this.client.get(`/api/now/table/${table}`, {
      params: { sysparm_query: query, sysparm_limit: 1 },
    });
    const results = searchRes.data?.result ?? [];

    const payload = this.mapToServiceNow(targetType, obj);

    if (results.length > 0) {
      const sysId: string = results[0].sys_id;
      await this.client.patch(`/api/now/table/${table}/${sysId}`, payload);
      return { action: "updated", sys_id: sysId };
    } else {
      const createRes = await this.client.post(`/api/now/table/${table}`, payload);
      return { action: "created", sys_id: createRes.data?.result?.sys_id };
    }
  }

  validate(targetType: string, obj: any): { errors: string[]; warnings: string[] } {
    const errors: string[] = [];
    const warnings: string[] = [];
    if (!obj.name) errors.push("name is required");
    return { errors, warnings };
  }

  private resolveTable(targetType: string): string {
    const map: Record<string, string> = {
      cmdb_ci_vm_instance: "cmdb_ci_vm_instance",
      cmdb_ci_server: "cmdb_ci_server",
      cmdb_ci_network_adapter: "cmdb_ci_network_adapter",
      cmdb_ci_ip_address: "cmdb_ci_ip_address",
      VirtualMachine: "cmdb_ci_vm_instance", // friendly alias
      Server: "cmdb_ci_server",
    };
    return map[targetType] ?? targetType;
  }

  private mapToServiceNow(targetType: string, obj: any): Record<string, any> {
    const payload: Record<string, any> = { name: obj.name };
    if (obj.vcpus !== undefined)  payload.cpu_core_count = obj.vcpus;
    if (obj.memory !== undefined) payload.ram = obj.memory;
    if (obj.platform)             payload.os = obj.platform;
    if (obj.primaryIp4)           payload.ip_address = obj.primaryIp4;
    if (obj.status)               payload.operational_status = obj.status === "running" ? "1" : "6";
    return payload;
  }
}
```

## 12. Constraints and invariants that must never be broken

These are architectural decisions baked into the codebase. Any change that violates them

### GATE invariants (from `server/services/gate-design-principle.ts`)

1. **Gate evaluation cannot be skipped.** There is no `--skip-gate` flag, no admin bypass, no environment variable that disables the gate.

2. **Provider hints cannot grant automation access.** `GateEvaluator.evaluateGate()` takes a `providerHintsUsed: boolean` parameter. If `true`, it throws `INVARIANT VIOLATION`. Never pass `true`.

3. **Gate runs as a first-class phase before inventory generation.** The `runGatePhase()` call must always precede `readAllowedAssets()`. Inventory generation reads from `gateStore`, never triggers evaluation.

4. **Removing CMDB governance immediately removes automation access.** Gate decisions are ephemeral (in-memory). They are re-evaluated on every sync. There is no persistent "approved" state.

5. **`asset_id` is the stable identity.** `asset_id = hash(providerId + vmName)`. VM names can change. `asset_id` does not.

### Secret invariants (from `server/services/secrets.ts`)

6. **The `enc:v1:` prefix is the format contract.** Never change the prefix or the format (`nonce:tag:ciphertext`). Changing it breaks all existing encrypted secrets in the database.

7. **`ENCRYPTION_KEY` must be a 64-character hex string (32 bytes).** Any other length throws at startup.

8. **Secrets are decrypted only immediately before use.** Never store decrypted secrets in variables that live beyond the scope of a single API call.

### Architecture invariants

9. **Provider sync does not write to CMDB.** `SyncWorker` caches to `external_objects` only. CMDB writes happen only through the pipeline sync path.

10. **Provider tags are always namespaced.** Tags written to NetBox from a provider must be prefixed with `{provider_kind}_` (e.g. `proxmox_node/pve1`). They must never overwrite governance fields.

## 13. Environment variable reference

| Variable | Required | Description |
|----------|----------|-------------|
| `DATABASE_URL` | Yes | PostgreSQL connection string |
| `ENCRYPTION_KEY` | Yes (prod) | 64-char hex string for AES-256 secret encryption. Generate: `openssl rand -hex 32` |
| `JWT_SECRET` | Yes | JWT signing secret. Generate: `openssl rand -hex 32` |
| `SESSION_SECRET` | Yes | Session signing secret. Generate: `openssl rand -hex 32` |
| `PORT` | No | HTTP port (default: 5000) |
| `NODE_ENV` | No | `production` or `development` (default: development) |
| `AUTH_DISABLE` | No | Dev only. Set to `true` to bypass authentication. Hard-fails with 403 in production. |
| `AWX_URL` | No | AWX base URL. Can also be set via the Settings UI. |
| `AWX_TOKEN` | No | AWX personal access token. Encrypted at rest if set via UI. |
