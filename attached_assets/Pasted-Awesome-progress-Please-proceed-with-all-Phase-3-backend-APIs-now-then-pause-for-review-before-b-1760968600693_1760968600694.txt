# Phase 3 — Backend API Spec (BDP)

## 0) Principles

* **Auth/RBAC:** admin → full; operator → dry-run & sync; viewer → read-only.
* **Idempotent writes:** use `matchBy` (e.g., `custom_fields.ext_id`) in adapters.
* **Dry-run by default:** never write on test endpoints.
* **Errors:** standardized JSON (see “Errors” section).
* **Modularity:** split routes into files (`routes/pipelines.ts`, `routes/pipeline-mappings.ts`, `routes/pipeline-runs.ts`) to avoid a huge `routes.ts`.

## 2) Pipelines (CRUD + runs)

### POST `/api/pipelines`

**Body**

```json
{ "name":"Proxmox→NetBox", "providerAccountId":"...", "cmdbAccountId":"..." }
```

**Resp 201**

```json
{ "id":"...", "name":"Proxmox→NetBox", "enabled":false, "version":1, "providerAccountId":"...", "cmdbAccountId":"..." }
```

### GET `/api/pipelines/:id`

**Resp 200**

```json
{
  "id":"...", "name":"...", "enabled":true, "version":3, "schedule_cron":"0 2 * * *",
  "providerAccountId":"...", "cmdbAccountId":"...",
  "lastRun":{"id":"...","status":"ok","started_at":"...","finished_at":"...","summary":{"created":2,"updated":7}}

```

### PATCH `/api/pipelines/:id`

**Body** (any subset)


**Resp 200** current pipeline object

**Resp 200**

```json
{ "items":[{"id":"...","status":"ok","dry_run":false,"started_at":"...","finished_at":"...","summary":{"created":2,"updated":7,"errors":0}}] }
```

## 3) Pipeline Mappings

### POST `/api/pipelines/:id/mappings`

**Body**

```json
{ "sourceType":"Vm", "targetType":"NetBox.VirtualMachine" }
```

**Resp 201**

```json
{ "id":"...", "pipeline_id":"...", "sourceType":"Vm", "targetType":"NetBox.VirtualMachine", "rules":null, "status":"draft" }
```

### GET `/api/pipelines/:id/mappings/:mapId`

**Resp 200**

```json
{ "id":"...","pipeline_id":"...","sourceType":"Vm","targetType":"NetBox.VirtualMachine","rules":{ /* current rules */ } }
```

### PATCH `/api/pipelines/:id/mappings/:mapId`

* Save **entire** `rules` object; bump `pipelines.version += 1`.
  **Body**

```json
{ "rules": { "target":"NetBox.VirtualMachine", "matchBy":["custom_fields.ext_id"], "fields":[...], "children":[...], "conflicts":{...}, "lookup_tables":{...} } }
```

**Resp 200** returns mapping with saved `rules` and updated pipeline version info.

### POST `/api/pipelines/:id/mappings/:mapId/test`

**Body**

```json
{ "sampleId":"prov-abc:Vm:1" }
```

**Resp 200**

```json
{
  "ok": true,
  "targetType":"NetBox.VirtualMachine",
  "transformed": { /* adapter-ready object */ },
  "validation": { "errors":[], "warnings":[] }
}
```

## 4) Dry-Run & Sync

### POST `/api/pipelines/:id/dry-run`

* Execute rules **without writing** to target.
  **Resp 200**

```json
{
  "status":"ok",
  "counts":{"created":12,"updated":37,"unchanged":402,"removed":5,"errors":3},
  "notes":["16 VMs missing primary_ip","5 invalid tenant mapping"],
  "examples":[
    {"action":"update","target":"VirtualMachine","name":"vm01","changes":{"platform":{"from":"windows","to":"linux"}}}
  ],
  "runId":"..."  // store as pipeline_runs with dry_run=true
}
```

### POST `/api/pipelines/:id/sync`

* Enqueue **bdp-sync** worker.
  **Resp 202**

```json
{ "runId":"..." }
```

## 8) Errors (standard format)

* **HTTP 400** validation: `{ "error":"validation_error", "details":[{"path":"schedule_cron","msg":"invalid cron"}] }`
* **HTTP 401/403** authz: `{ "error":"unauthorized" }` / `{ "error":"forbidden" }`
* **HTTP 404**: `{ "error":"not_found" }`
* **HTTP 422** adapter/transform error: `{ "error":"transform_error", "msg":"regex_extract failed on field platform" }`
* **HTTP 500**: `{ "error":"internal", "traceId":"..." }`

Log `traceId` and include in `pipeline_runs.log_path`/logs.

---

## 9) Worker semantics

* **Dry-run worker**: build transformed targets, call `validate()` only; compute diffs vs current CMDB state (by `matchBy`), **do not write**; summarize counts.
* **Sync worker**: same, then **write** via adapter `upsert()`; respect field conflicts; summary + first N errors in `summary.errors`.
