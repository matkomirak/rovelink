Task 2 — Require orgId when platform_admin creates tenant users
---------------------------------------------------------------

File:
  server/routes.ts

Endpoint:
  POST /api/users

Problem:
platform_admin can create viewer/operator/admin users with orgId null.

Required behavior:
- platform_admin may have orgId null.
- viewer/operator/admin must have orgId.
- Optional: validate that orgId exists before user creation.

Suggested validation:

  const effectiveRole = role ?? "viewer";

  if (effectiveRole !== "platform_admin" && !orgId) {
    return res.status(400).json({
      message: "orgId is required for viewer, operator, and admin users"
    });
  }

Acceptance:
- Creating viewer/operator/admin without orgId returns 400.
- Creating platform_admin without orgId is allowed.
- Creating viewer/operator/admin with orgId works.
- Tests added.
- npm test passes.
