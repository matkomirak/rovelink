Task 4 — Decide whether group cache should remain global or become org-scoped
----------------------------------------------------------------------------

Files:

    server/routes.ts
    server/storage.ts
    shared/schema.ts if schema changes are needed

Current state:

    POST /api/housekeeping/rebuild-groups-cache

is platform_admin-only, which is safe for a global cache.

But the group cache itself is still global:

    clearGroupCache()
    addGroupCache(...)

Required decision:

Option A — keep global:

- Keep endpoint platform_admin-only.
- Document group cache as platform-wide.
- Ensure normal org users never receive global cached group data unless that is intended.

Option B — make org-scoped:

- Add orgId to groupCache.
- clearGroupCache(orgId)
- addGroupCache(orgId, item)
- list groups by orgId.
- Admin can rebuild only own org cache.

Acceptance criteria:

- Group cache scope is documented.
- Normal org admins cannot clear/rebuild global cache.
- User-facing group suggestions are org-scoped.
