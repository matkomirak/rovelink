Data model (Postgres)

provider_accounts
id, kind, name, enabled bool, schedule_cron text, config jsonb, created_at, updated_at

sync_runs
id, provider_account_id, started_at, finished_at, status text, counts jsonb, error text, log_path text

external_objects
provider_account_id, external_id, provider_kind, netbox_type, netbox_id int, cached_payload jsonb, last_synced_at

Scheduler + workers

Scheduler service reads provider_accounts.schedule_cron and enqueues syncs (use a cron lib; validate with a parser).

Sync worker steps per account:

Get collector by kind.

listVms() → normalize.

Map to NetBox payloads; upsert (idempotent).

Record sync_runs with counts: {created, updated, unchanged, errors, removed}.

On error, set status=failed and save first 20 errors.

Group cache: a small table or JSON file with NetBox groups for the limit autocomplete; refresh on demand + nightly.

Housekeeping job definitions

Ensure NetBox schema: verify/create custom fields & required tags; report changes.

Prune stale: mark external_objects not seen for N days as removed; optional delete (flag first).

Retry last failed sync: find most recent status=failed per provider; enqueue.

Rotate tokens: if config has expiring tokens, prompt/flag; for Azure client creds, just test/alert.
