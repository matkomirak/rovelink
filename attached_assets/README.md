# Historical Development Assets

The pasted briefs in this directory are archived implementation proposals, not
current setup instructions or feature guarantees. They may describe deferred,
superseded, or experimental behavior. Use the root README, CONTRIBUTING.md,
SECURITY.md, and current source/tests for the alpha's supported scope.

Examples in archived briefs are synthetic development placeholders. Never use
their sample credentials or auth-bypass instructions for deployment. Historical
branding has been anonymized where appropriate. Generated Rovelink artwork is
retained; unused screenshots with environment details and obsolete branding art
have been removed from the current tree.

Removal from this directory does not erase Git history. See
[the sanitization audit](../docs/public-sanitization-audit.md) for remaining
public-release blockers. New screenshots must use synthetic data and must not
contain credentials, internal addresses, customer identifiers, or cloud IDs.
